A make.fun bounty entry: one original line roasting a gadget used every day.

## The line

> My microwave beeps five times when the food is done, like it's personally offended I took more than three seconds to open the door.

## How it works

`main.py` (Python 3.13, standard library only) writes the roast line
deterministically to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default
`/output/entry.txt`). Run it twice and the output is byte-identical.

```sh
python3 main.py
cat /output/entry.txt
```
